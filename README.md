# Bike Speedometer ESP32-S3

Автономный велокомпьютер на ESP32-S3 с TFT-экраном, сенсорным управлением, SD-картой, USB Mass Storage и проводным датчиком скорости.

Проект является новой версией старого спидометра, где ESP32 считывал датчик Холла и передавал скорость на Android-приложение. Новая версия должна работать самостоятельно: телефон больше не является основным дисплеем.

## Основной функционал

Финальная прошивка должна:

- считать скорость по импульсам проводного датчика Холла;
- отображать текущую скорость на экране;
- отображать график скорости;
- показывать максимальную скорость;
- показывать среднюю скорость;
- показывать длительность заезда;
- показывать километраж текущего заезда;
- поддерживать старт заезда;
- поддерживать паузу;
- поддерживать продолжение после паузы;
- поддерживать завершение заезда;
- записывать данные заезда на SD-карту;
- подключаться к компьютеру как USB Mass Storage для доступа к файлам на SD-карте;
- восстанавливать незавершённый заезд после перезагрузки в состоянии `PAUSED`.

## Текущий тестовый этап

На текущем этапе нужно проверить железо и базовый интерфейс.

Должно быть реализовано:

- главное меню;
- экран настроек;
- диагностика экрана;
- Paint-тест для тача и отрисовки;
- тест raw touch координат;
- обнаружение SD-карты;
- создание тестового текстового файла на SD;
- чтение тестового файла обратно;
- USB Mass Storage с доступом к SD-карте;
- тест входа датчика на GPIO4;
- заглушка измерителя батареи;
- экран ошибки при отсутствии SD-карты с кнопкой продолжения без сохранения данных.

Датчик скорости и измеритель заряда могут быть физически не припаяны. Прошивка обязана запускаться и работать без них.

## Железо

Контроллер:

```text
ESP32-S3-N16R8
16 MB Flash
8 MB PSRAM
Dual Type-C development board
PlatformIO + Arduino framework
```

Экран:

```text
3.5" SPI TFT
Driver: ST7796
Touch: FT6336 over I2C
SD: SPI, shared with display SPI bus
```

Основные пины:

```text
LCD_CS    GPIO10
LCD_RST   GPIO14
LCD_DC    GPIO9
SPI_MOSI  GPIO11
SPI_SCK   GPIO12
SPI_MISO  GPIO13
LCD_BL    GPIO47

CTP_SCL   GPIO18
CTP_RST   GPIO17
CTP_SDA   GPIO8
CTP_INT   GPIO16

SD_CS     GPIO15

USB_D-    GPIO19
USB_D+    GPIO20

HALL      GPIO4
```

Полная распиновка находится в `docs/HARDWARE.md`.

## Управление

Главный экран заезда:

- снизу кнопки `Start`, `Pause/Resume`, `Stop/Finish`;
- сверху справа кнопка выхода в меню/настройки;
- по центру перелистываемые страницы:
  - крупная скорость;
  - график скорости;
  - статистика.

## Логика скорости

Скорость считается по времени между импульсами датчика Холла.

Если нового импульса нет, прошивка не должна бесконечно показывать старую скорость. Вместо этого используется предполагаемая скорость: прошивка считает скорость так, будто новый оборот колеса завершился в текущий момент. Если такая скорость падает ниже порога остановки, скорость считается нулевой.

Порог остановки по умолчанию:

```text
3 km/h
```

Окружность колеса и порог остановки должны храниться в конфиге и редактироваться из настроек.

## SD и USB

На первом этапе формат логов поездок не фиксируется окончательно.

Обязательно для теста:

```text
/BIKE_SPEEDOMETER_SD_TEST.txt
```

Файл должен создаваться на SD-карте, читаться обратно прошивкой и быть видимым на компьютере через USB Mass Storage.

Когда SD-карта отдана компьютеру как USB Mass Storage, прошивка не должна параллельно писать на неё.

## Сборка

Проект должен собираться через PlatformIO:

```bash
pio run
```

Загрузка на плату:

```bash
pio run -t upload
```

Монитор порта:

```bash
pio device monitor
```

Текущая тестовая прошивка уже содержит `platformio.ini` для:

- `esp32-s3-devkitc-1` как базовой платы ESP32-S3-N16R8;
- 16 MB Flash и 8 MB PSRAM;
- Arduino framework;
- TFT_eSPI с compile-time настройкой ST7796 и SPI-пинов;
- ArduinoJson для `/config/bike_config.json`;
- native USB ESP32-S3 для USB Mass Storage.

Если локальная версия Arduino-ESP32 не содержит `USBMSC.h` или FatFs `diskio.h`,
экран USB Storage покажет, что USB MSC не скомпилирован для установленного core.
Остальные тестовые экраны при этом продолжают работать.

## Текущая структура прошивки

Код разделён на модули:

```text
src/
  main.cpp
  config/      GPIO и настройки по умолчанию
  display/     TFT_eSPI и подсветка
  touch/       минимальный FT6336 I2C-драйвер
  ui/          меню, диагностика, настройки, экран заезда
  speed/       GPIO4 interrupt, расчёт скорости, ride state machine
  storage/     SD, SD test file, config JSON, recovery
  usb/         USB Mass Storage wrapper
  battery/     отключённая заглушка батареи
```

## Ручная проверка тестовой версии

После прошивки проверить по `docs/TEST_PLAN.md`:

1. Boot log в Serial: версия, Flash, PSRAM, CPU.
2. Boot без SD: экран `SD card not found`, кнопки `Retry` и `Continue`.
3. `Diagnostics -> Display test`.
4. `Diagnostics -> Touch raw test`.
5. `Diagnostics -> Paint test`.
6. `Diagnostics -> SD test` с файлом `/BIKE_SPEEDOMETER_SD_TEST.txt`.
7. `USB Storage` при вставленной SD.
8. `Diagnostics -> Sensor test` для GPIO4 без датчика и с имитацией сигнала.
9. `Ride`: Start, Pause, Resume, Stop, страницы Speed/Graph/Stats.
10. `Settings`: окружность колеса, stop threshold, яркость, полярность датчика.

## Важные ограничения

- Не менять GPIO без явного решения.
- Не использовать GPIO19/GPIO20 как обычные GPIO: они заняты USB.
- Не использовать GPIO8-18 и GPIO47 для других задач: они заняты экраном, тачем и SD.
- Не падать без SD-карты.
- Не падать без датчика.
- Не падать без батарейного измерителя.
- Не писать на SD во время USB Mass Storage.
